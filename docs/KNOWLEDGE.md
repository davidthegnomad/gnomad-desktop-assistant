# Gnomad knowledge base

Files live in the app data folder: `gnomad/knowledge/`.

| Folder | Purpose |
|--------|---------|
| `skills/` | Skill instructions (`.md`, `.txt`, `.json`) |
| `agents/` | Agent personas and domain knowledge |
| `preferences/` | `user-preferences.md` — appended when you change settings |
| `uploads/` | General reference uploads |

`INDEX.md` is updated automatically when files are added or removed.

Use the **book icon** in the header or **Knowledge & skills** in the left sidebar → **Add files** to import documents. Uploaded skills and agent briefs are included in chat via `get_agent_context_bundle`.
