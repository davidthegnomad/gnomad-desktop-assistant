[0.1.0-alpha] — 2026-05-31

First public alpha.

Added

  • macOS menu-bar accessory with mushroom tray icon
  • Linux .deb, .rpm, and AppImage packages
  • Windows .msi / NSIS installer (CI)
  • Gemini-style chat UI, collapsible sidebar, chat history
  • DeepSeek and Ollama chat integration
  • Knowledge base and skills library
  • Native File / Edit / View / Window / Help menus (windowed mode)
  • GitHub Actions multi-platform builds
  • Project site

Known limitations (alpha)

  • Requires manual API key / Ollama setup
  • macOS permissions for automation may need re-grant after updates
  • Linux builds target x86_64 in CI; ARM requires local build
  • Snap / Flatpak not yet available
